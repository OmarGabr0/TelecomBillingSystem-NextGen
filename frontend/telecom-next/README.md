# Telecom Billing Dashboard Frontend

Modern fintech UI built on Next.js with animations and responsive design. Backend APIs remain unchanged — this is a pure frontend enhancement.

## What's Included

- **Phase 1**: Installed `framer-motion`, `lucide-react`, and extended Tailwind CSS with glassmorphism, gradients, and keyframe animations.
- **Phase 2**: Reusable component library — Sidebar, Navbar, DashboardLayout, Button, Card, Badge, Input, Select, Textarea, Table, StatBox, Skeleton, LoadingOverlay, ToastContainer.
- **Phase 3**: Redesigned admin dashboard with animated navigation, premium navbar, gradient stat cards, modern tables, and responsive layout.
- **Phase 4**: Form components with loading states and global toast notifications (`window.showToast()`).

## Getting Started

```bash
cd frontend/telecom-next
npm install
npm run dev
```

Open [http://localhost:3000/admin](http://localhost:3000/admin) to view the enhanced dashboard.
